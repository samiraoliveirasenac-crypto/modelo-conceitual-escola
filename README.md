# modelo-conceitual-escola
Projeto de atividade escolar sobre Modelo Conceitual de Banco de Dados, contendo entidades, atributos e relacionamentos do sistema escolar.

Projeto desenvolvido para atividade escolar com foco em Banco de Dados, apresentando o modelo conceitual de uma escola com as entidades:

Aluno
Professor
Curso

Relacionamentos:

Aluno faz Curso
Professor ministra Curso

Curso escolhido:

Banco de Dados Básico
Carga Horária: 40 horas.
